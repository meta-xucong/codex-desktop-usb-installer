# 流量猎手 - Traffic Hunter

## Overview

解决"用户从哪来"的问题。不追求泛流量，只 hunting 精准流量。从渠道选择到内容矩阵，搭建可持续的获客系统。

## Use Cases

- 冷启动阶段寻找第一批用户
- 搭建多平台内容矩阵
- 设计病毒传播机制
- 优化现有渠道的获客效率

## Workflow

### STEP 1: 渠道诊断

评估现有渠道的 3 个维度：

| 维度 | 问题 | 评估标准 |
|------|------|----------|
| 精准度 | 用户匹配度 | 转化率 > 3% 为合格 |
| 成本 | 获客成本 | CAC < LTV/3 为健康 |
| 规模 | 流量上限 | 能否支撑业务增长目标 |

### STEP 2: 流量渠道地图

**免费渠道（慢但稳）**
- SEO/内容营销：长尾流量，复利效应
- 社交媒体：小红书、抖音、B站、知乎
- 社群运营：微信群、Discord、知识星球
- 异业合作：资源互换、联合推广

**付费渠道（快但贵）**
- 信息流广告：抖音、朋友圈、小红书
- 搜索广告：百度、知乎、小红书
- KOL/KOC 投放：垂类达人合作
- 私域投流：朋友圈广告引流到私域

**裂变渠道（杠杆大）**
- 邀请奖励：老带新机制
- 拼团/砍价：社交裂变
- 内容裂变：打卡、测评、UGC

### STEP 3: 内容矩阵设计

**金字塔内容结构**

```
        ┌─────────┐
        │  爆款   │  ← 1% 内容，带来 80% 流量
        │  内容   │     钩子型、争议型、干货型
        ├─────────┤
        │  专业   │  ← 10% 内容，建立信任
        │  内容   │     案例、方法论、深度分析
        ├─────────┤
        │  日常   │  ← 89% 内容，维持活跃
        │  内容   │     观点、动态、互动
        └─────────┘
```

**钩子设计公式**

| 钩子类型 | 公式 | 示例 |
|----------|------|------|
| 痛点型 | 你是否有____的烦恼？ | "你是否也有写不出文案的烦恼？" |
| 好奇型 | ____的秘密/真相 | "月入 10 万的文案都在用的 3 个秘密" |
| 利益型 | 如何____（获得____） | "如何用 1 小时写出转化率 10% 的文案" |
| 身份型 | ____的人都在____ | "顶级操盘手都在用的复盘方法" |

### STEP 4: 冷启动策略

**0-100 用户获取**

1. **精准狙击** - 找到 10 个目标用户的聚集地
2. **价值先行** - 先给价值，再谈转化
3. **私域沉淀** - 把公域流量转到私域
4. **口碑裂变** - 让早期用户成为你的销售

## Best Practices

- 不要同时做所有渠道，先打透一个
- 内容要有钩子，但不要标题党
- 免费流量要配合付费流量放大
- 流量不是目的，转化才是

## Example Prompts

- "我的产品刚上线，帮我设计一个冷启动获客方案"
- "分析一下小红书获客的可行性"
- "帮我设计一个内容矩阵，覆盖知乎、小红书、抖音"
- "我的获客成本太高了，帮我优化一下"

## Output Example

```
【流量现状诊断】
当前主要渠道：
- 渠道 1：小红书自然流量，转化率 1.2%，CAC ¥50
- 渠道 2：朋友圈广告，转化率 0.8%，CAC ¥120
问题识别：
- 小红书转化率偏低，可能是 Landing Page 问题
- 朋友圈广告 CAC 过高，需要优化素材

【渠道优先级】
第一优先级（立即做）：
- 渠道：小红书 SEO + 爆款内容
- 原因：平台红利期，竞争小，用户精准
- 预期 ROI：1:5

第二优先级（验证后做）：
- 渠道：知乎长尾内容
- 验证方式：先发布 10 篇测试流量

【内容矩阵规划】

- 内容类型：干货图文 + 短视频
- 发布频率：日更
- 爆款钩子方向：薪资谈判、职场避坑、简历优化

平台 2：知乎
- 内容类型：深度长文 + 回答
- 发布频率：周更 2-3 篇
- 爆款钩子方向：行业分析、职业发展、技能提升

【冷启动执行计划】

- 注册账号，完善资料

- 分析数据，找到爆款方向

Week 2：
- 加大爆款方向内容产出
- 开始评论区互动引流
- 搭建私域承接流程

Week 3-4：
- 稳定日更节奏
- 测试付费投放
- 优化转化链路

【关键指标】
- 目标流量：月新增 5000 访客
- 目标转化率：3%
- 目标 CAC：¥30
```
