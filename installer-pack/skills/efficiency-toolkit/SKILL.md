# ⚡ 效率工具箱

日常效率提升与任务管理服务。

## 核心能力

1. **文件整理** — 批量重命名、分类归档、目录结构化
2. **笔记管理** — 标签体系、知识库构建、笔记整理
3. **日程规划** — 待办提取、时间块安排、优先级排序
4. **密码管理** — 强密码生成、安全存储建议

## 使用场景

- "整理桌面上的文件，按日期归档"
- "帮我设计一个笔记标签体系"
- "从这段文字里提取所有待办事项"
- "生成一个安全的密码"

## 文件整理规范

### 命名规范
```
[日期]-[项目/类别]-[描述]-[版本]

示例：
2026-04-16-项目X-需求文档-v1.0.docx
2026-04-16-周报-销售部.md
```

### 目录结构模板
```
项目文件夹/
├── 01-需求文档/
├── 02-设计稿/
├── 03-开发文档/
├── 04-会议记录/
├── 05-交付物/
└── 99-归档/
```

### 整理流程
1. **只读盘点**：先列出待整理文件的路径、类型、大小、修改时间和拟分类；只做读取和预览，不先重命名、移动、删除或覆盖。
2. **分类与命名建议**：按项目/日期/类型分组，并给出建议的新名称和目标目录。实际重命名或移动也属于文件变更，必须先列出每项的明确源路径、目标路径和操作，并取得用户授权。
3. **疑似重复核验**：文件名相同只能作为候选线索。比较文件哈希；必要时再检查内容，确认相同后才可标为重复候选。先报告每个候选的路径、哈希/核验结果和建议保留项，不因名称相似或相同直接删除。
4. **预览与授权**：执行前提供完整预览清单。删除、移动、重命名或覆盖必须逐项列明确切路径和操作，并取得用户授权；用户原始请求只有在已经明确列全这些路径和操作时才算授权。未授权的项目只给建议，不执行；授权范围以外不操作。
5. **冲突处理**：目标路径已存在或无法确认目标内容时，默认跳过该项并报告冲突；不覆盖，也不擅自改名绕过冲突。只有用户明确授权了对应路径和操作后才继续。
6. **归档**：可建议归档目录和候选文件；实际移动旧文件前，按上述规则逐项列明源路径、归档目标路径并取得授权。

任何步骤都不得把“整理”“去重”或“归档”的笼统请求解释为删除、移动或覆盖的授权。用户未授权时，交付只读盘点结果、分类/命名建议和待确认操作清单。

## 日程规划方法

### 待办提取流程
1. 从各种来源收集（邮件、会议、聊天）
2. 统一格式：`[行动] + [负责人] + [截止日期]`
3. 分类优先级
4. 录入任务管理工具

### 优先级矩阵
| 紧急\重要 | 重要 | 不重要 |
|----------|------|--------|
| **紧急** | 立即做 | 委托/快速处理 |
| **不紧急** | 计划做 | 删除/延后 |

### 时间块规划
```
09:00-10:00  深度工作（重要项目）
10:00-10:30  邮件/沟通
10:30-12:00  会议/协作
14:00-16:00  深度工作
16:00-17:00  整理/规划
17:00-17:30  回顾/明日计划
```

## 密码管理规范

### 密码创建规则
- 每个账号使用不同的密码；不要跨网站或服务复用密码。
- 使用密码管理器生成并保存长且随机的唯一密码。无法使用密码管理器时，可选用足够长且不易猜测的口令短语。
- 对仅依赖密码的账号，优先遵循当前服务要求；NIST 当前指南对单因素密码给出的最低长度为 15 个字符。服务允许时应使用更长的密码。
- 避免姓名、生日、常见短语和可预测的连续字符；不要把密码以明文写入普通笔记或共享文档。

### 账号管理
| 账号类型 | 管理建议 |
|-----|---------|
| 核心账号（邮箱、金融） | 使用独立的高强度密码；开启多因素认证（MFA）；保护好密码管理器主口令和恢复方式 |
| 工作账号 | 使用独立密码并遵守组织策略；优先使用组织提供的 SSO/MFA |
| 普通网站账号 | 同样使用各不相同的密码；由密码管理器保存，不因账号重要性较低而复用 |
| 临时账号 | 使用独立随机密码；服务不再需要时按其流程关闭账号 |

### 安全建议
- 使用信誉良好的密码管理器生成并保存唯一密码，并为密码库开启 MFA。
- 账号支持时开启 MFA 或使用 Passkey。
- 发现泄露、可疑登录或服务通知凭据暴露时，立即更换受影响凭据；不要求在没有泄露迹象时按固定周期机械轮换，除非组织或服务策略要求。
- 避免在公共或共享设备上保存密码；不要把密码写入明文笔记、日志或共享文档。

参考： [NIST How Do I Create a Good Password?](https://www.nist.gov/cybersecurity-and-privacy/how-do-i-create-good-password)；[NIST SP 800-63B-4](https://pages.nist.gov/800-63-4/sp800-63b.html)。

## 信息检索与整理

### 快速搜索技巧
需要查找外部信息时，优先使用当前 Codex 会话提供的网页搜索/浏览能力。当前会话不能联网时，
只整理用户给出的链接、文件和文本，并明确哪些信息尚未核验。

### 搜索结果整理
将搜索结果整理到笔记时：
1. 标注搜索日期和关键词
2. 提取核心要点，删除冗余信息
3. 标注信息来源链接
4. 添加个人备注和行动计划
