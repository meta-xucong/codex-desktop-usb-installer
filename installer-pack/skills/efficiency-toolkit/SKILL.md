# ⚡ 效率工具箱

日常效率提升与任务管理服务。

## 核心能力

1. **文件整理** — 批量重命名、分类归档、目录结构化
2. **笔记管理** — 标签体系、知识库构建、笔记整理
3. **日程规划** — 待办提取、时间块安排、优先级排序
4. **密码管理** — 强密码生成、安全存储建议

## 使用场景

- "整理桌面上的文件，按日期归档"
- "帮我设计一个笔记标签体系"
- "从这段文字里提取所有待办事项"
- "生成一个安全的密码"

## 文件整理规范

### 命名规范
```
[日期]-[项目/类别]-[描述]-[版本]

示例：
2026-04-16-项目X-需求文档-v1.0.docx
2026-04-16-周报-销售部.md
```

### 目录结构模板
```
项目文件夹/
├── 01-需求文档/
├── 02-设计稿/
├── 03-开发文档/
├── 04-会议记录/
├── 05-交付物/
└── 99-归档/
```

### 整理流程
1. **分类**：按项目/日期/类型分组
2. **命名**：统一命名规范
3. **去重**：删除重复文件
4. **归档**：旧文件移入归档目录

## 日程规划方法

### 待办提取流程
1. 从各种来源收集（邮件、会议、聊天）
2. 统一格式：`[行动] + [负责人] + [截止日期]`
3. 分类优先级
4. 录入任务管理工具

### 优先级矩阵
| 紧急\重要 | 重要 | 不重要 |
|----------|------|--------|
| **紧急** | 立即做 | 委托/快速处理 |
| **不紧急** | 计划做 | 删除/延后 |

### 时间块规划
```
09:00-10:00  深度工作（重要项目）
10:00-10:30  邮件/沟通
10:30-12:00  会议/协作
14:00-16:00  深度工作
16:00-17:00  整理/规划
17:00-17:30  回顾/明日计划
```

## 密码管理规范

### 强密码生成规则
- 长度：至少 12 位
- 组成：大小写字母 + 数字 + 特殊符号
- 避免：生日、姓名、连续字符

### 密码分类
| 类型 | 示例 | 管理建议 |
|-----|------|---------|
| 核心密码 | 银行、邮箱 | 唯一、定期更换 |
| 工作密码 | 公司系统 | 按公司政策 |
| 普通密码 | 社交网站 | 可适度复用 |
| 临时密码 | 试用账号 | 用完即弃 |

### 安全建议
- 使用密码管理器（1Password、Bitwarden）
- 开启双因素认证（2FA）
- 定期更换核心密码
- 不在公共设备上保存密码

## 信息检索与整理

### 快速搜索技巧
需要查找外部信息时，优先使用当前 Codex 会话提供的网页搜索/浏览能力。当前会话不能联网时，
只整理用户给出的链接、文件和文本，并明确哪些信息尚未核验。

### 搜索结果整理
将搜索结果整理到笔记时：
1. 标注搜索日期和关键词
2. 提取核心要点，删除冗余信息
3. 标注信息来源链接
4. 添加个人备注和行动计划
