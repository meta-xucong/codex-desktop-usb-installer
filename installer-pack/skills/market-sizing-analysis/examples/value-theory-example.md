# Hypothetical Value-Theory Example

> **Synthetic teaching example.** All inputs below are invented to show arithmetic, not to describe any real product, customer, or market.

Assume a hypothetical tool saves one customer 100 hours per year. For demonstration, assume the customer values an hour at $50 and the tool eliminates 30% of the measured workload.

- Hypothetical annual problem cost = 100 × $50 = $5,000
- Hypothetical annual value created = $5,000 × 30% = $1,500

Assume a hypothetical tested price of $600/year for this example only. The price is not inferred from a universal willingness-to-pay percentage.

- Value-to-price ratio = $1,500 / $600 = 2.5×
- If a hypothetical 5,000 customers meet explicit eligibility criteria, illustrative TAM = 5,000 × $600 = $3,000,000/year

A real analysis must establish hours saved and loaded labor cost using customer evidence, test willingness to pay with observed behavior where possible, document eligible customer counts, and label every assumption. Do not generalize this example's values.
