# 主机安全检查边界

本 Skill 会随安装包复制并在配置层面默认启用，但默认启用不代表已经拥有管理员权限或所有
Windows 安全后端。只有实际探针成功后才能报告主机状态；缺少工具、权限、策略或设备状态时，
必须明确返回“安全检查后端不可用/需要管理员权限”，不伪造通过或失败结论，也不得省略权限缺口。

## 可用路径

如果用户明确要求 Windows 安全检查，应在确认目标主机和权限后，使用系统自带的只读工具逐项检查：

- Windows 安全中心、Windows Update、防火墙和 BitLocker 状态
- 当前监听端口、远程桌面和 SSH 暴露面
- 备份可恢复性、磁盘空间和关键软件版本

任何修改防火墙、远程访问、启动项、注册表或磁盘配置的操作，都必须先说明风险并取得明确确认。

外部依赖名称：`external.windows-security-admin-tools`。未连接时只能输出检查清单和缺失依赖，不能
把清单当成实测结果。
