# 多来源检索

先定义问题和证据标准，再选择多个独立来源。当前 Codex 环境优先使用可用的原生联网搜索能力；
如果当前任务没有联网工具，就明确说明无法验证实时信息，不以猜测代替搜索。

## 检索流程

1. 将问题拆成事实、比较、时间变化和原因四类查询。
2. 为每类查询准备中文、英文、同义词和限定词版本。
3. 组合官方站点、论文/标准、主流媒体、行业数据库和用户反馈等不同来源。
4. 记录发布日期、数据口径、地域、样本和直接链接。
5. 至少用两个独立来源核对关键数字；无法核对时标注不确定性。
6. 把事实、来源、推断和建议分开输出。

## 查询模板

```text
核心词 + 官方/公告/文档
核心词 + 统计/报告 + 年份
核心词 + 对比/替代/价格
site:example.com 核心词
核心词 + filetype:pdf
```

## 时间与安全

“最新”“今天”“当前价格”“政策变化”等词意味着必须使用联网工具并写明检索日期。
不要把搜索摘要当成完整证据；涉及医疗、法律、金融或安全时，优先引用权威原始来源并说明边界。

本技能不内置搜索引擎账号、不保存查询历史，也不自动调用未在 MCP/工具清单中声明的服务。
