# 📄 文档管家

专业文档处理与排版美化服务。

## 核心能力

1. **Markdown 排版美化** — 统一格式、优化层级、添加目录
2. **Word 文档处理** — 样式统一、页眉页脚、目录生成
3. **格式转换** — Markdown ↔ Word ↔ PDF 互转
4. **PPT 生成** — 根据大纲或内容自动生成幻灯片
5. **白板设计** — 流程图、思维导图、架构图

## 使用场景

- "把这份 Markdown 整理成正式 Word 文档"
- "给这份报告添加目录和页眉页脚"
- "根据这个大纲生成 PPT"
- "画一个项目流程图"

## Markdown 排版规范

### 标题层级
```markdown
# 一级标题（文档标题）
## 二级标题（章节）
### 三级标题（小节）
#### 四级标题（细节）
```

### 排版检查清单
- [ ] 标题层级连续，无跳级
- [ ] 代码块标注语言类型
- [ ] 列表符号统一（- 或 *）
- [ ] 中英文之间加空格
- [ ] 段落间空行分隔

## Word 文档规范

### 专业配色方案

**商务蓝系列（推荐默认）**
- 主色：`#1E3A5F`（深蓝）— 标题、重点
- 辅助色：`#4A90A4`（青蓝）— 二级标题、图表
- 强调色：`#E8913A`（橙金）— 重点标注、按钮
- 背景色：`#F8F9FA`（浅灰白）— 页面背景
- 文字色：`#2C3E50`（深灰）— 正文

**其他配色方案**
- 科技绿：`#0D7377` / `#14FFEC` / `#323232`
- 优雅紫：`#5B4B8A` / `#D4A5A5` / `#F9F9F9`
- 活力红：`#C0392B` / `#E74C3C` / `#ECF0F1`

### 标准样式设置

#### 字体规范
| 元素 | 中文字体 | 英文字体 | 字号 | 字重 | 颜色 |
|-----|---------|---------|------|-----|------|
| 封面标题 | 思源黑体 Heavy | Montserrat Bold | 36pt | Bold | 主色 `#1E3A5F` |
| 标题一 | 思源黑体 Bold | Montserrat Bold | 22pt | Bold | 主色 `#1E3A5F` |
| 标题二 | 思源黑体 Bold | Montserrat SemiBold | 16pt | Bold | 辅助色 `#4A90A4` |
| 标题三 | 思源黑体 Medium | Montserrat Medium | 14pt | Medium | 文字色 `#2C3E50` |
| 正文 | 思源宋体/微软雅黑 | Open Sans | 11pt | Regular | 文字色 `#2C3E50` |
| 注释 | 思源黑体 Regular | Open Sans | 9pt | Regular | `#7F8C8D` |

#### 段落格式
- **行距**：正文 1.6 倍，标题 1.2 倍
- **段前段后**：标题前 12pt、后 6pt；正文段前段后 3pt
- **首行缩进**：正文 2 字符（约 0.7cm）
- **对齐方式**：正文两端对齐，标题左对齐或居中

#### 页面设置
- **纸张**：A4（210mm × 297mm）
- **边距**：上 2.54cm / 下 2.54cm / 左 3.17cm / 右 3.17cm
- **页眉**：1.5cm，页脚：1.75cm

#### 页眉页脚样式
```
页眉：左侧公司/文档标识 | 右侧章节标题
页脚：左侧页码（第 X 页/共 Y 页）| 右侧日期
```
- 页眉线：0.5pt 单线，颜色 `#BDC3C7`
- 页码格式：`- 1 -` 或 `Page 1 of 10`

### 文档结构
1. **封面页**
   - 顶部：公司 Logo（如有）
   - 中部：大标题 + 副标题 + 日期
   - 底部：作者/部门/联系方式
   - 背景：纯色或浅色渐变

2. **目录页**
   - 自动生成，含页码
   - 样式：标题左对齐，页码右对齐，中间引导线
   - 层级缩进：二级标题缩进 1cm，三级缩进 2cm

3. **正文内容**
   - 分章节，每章新起一页（可选）
   - 图表编号：图 1-1、表 2-1
   - 页眉显示当前章节

4. **附录（如有）**
   - 参考资料、术语表、联系方式

### Word 生成代码规范
```python
from docx import Document
from docx.shared import Pt, RGBColor, Inches, Cm
from docx.enum.text import WD_ALIGN_PARAGRAPH
from docx.enum.style import WD_STYLE_TYPE

# 配色定义
PRIMARY_COLOR = RGBColor(30, 58, 95)      # #1E3A5F
SECONDARY_COLOR = RGBColor(74, 144, 164)  # #4A90A4
ACCENT_COLOR = RGBColor(232, 145, 58)     # #E8913A
TEXT_COLOR = RGBColor(44, 62, 80)         # #2C3E50

# 设置默认字体
def set_default_font(run, font_name='微软雅黑', font_size=11, bold=False, color=TEXT_COLOR):
    run.font.name = font_name
    run.font.size = Pt(font_size)
    run.font.bold = bold
    run.font.color.rgb = color
```

## PPT 生成原则

### 专业配色方案

**商务蓝（默认）**
```python
COLORS = {

    'secondary': RGBColor(74, 144, 164),  # 青蓝 #4A90A4
```

**渐变配色（高级感）**
- 卡片背景：`#F8F9FA` → `#FFFFFF`（左上到右下微渐变）
- 标题栏：`#1E3A5F` → `#4A90A4`（左到右渐变）

### 视觉元素规范

#### 卡片样式
- 圆角：8-12pt
- 阴影：轻微投影（offset 2pt, blur 4pt, 透明度 10%）
- 边框：0.5pt，颜色 `#E0E0E0` 或无边框
- 背景：纯白或极浅灰 `#FAFAFA`
- 悬停态（交互时）：轻微上浮 + 阴影加深

#### 图标使用
- 统一使用 Emoji 或一套图标库（如 Font Awesome）
- 图标大小：正文配 16-20pt，标题配 24-32pt
- 图标颜色：与卡片主题色或主色一致

#### 图表样式
- 柱状图：圆角柱体，主色/辅助色交替
- 折线图：2.5pt 线宽，数据点 6pt
- 饼图：分离式切片，标签外置
- 统一添加数据标签和图例

### 动画建议（如支持）
- 页面切换：淡入淡出（0.3s）
- 元素出现：从底部滑入（0.2s，依次延迟 0.1s）
- 避免：旋转、弹跳等过于活泼的动画

### 整体结构
1. **封面**（标题、副标题、演讲人、日期）
2. **目录/概览**（3-5 个章节预览）
3. **核心内容**（每章节 2-4 页）
4. **总结**（关键结论、行动项）
5. **致谢/Q&A**（联系方式、下一步）

## 文档摘要与浓缩

### 一页纸精华提炼
将长文档浓缩为一页纸核心内容：

**提炼步骤：**
1. **识别核心信息**：目标、结论、关键数据、行动项
2. **结构化重组**：按重要性排序，非按原文顺序
3. **可视化呈现**：使用图表、图标替代大段文字
4. **精简表达**：删除修饰词，保留事实和观点

**一页纸模板：**
```
┌─────────────────────────────────────┐
│  [文档标题] - 一页纸精华              │
├─────────────────────────────────────┤
│  🎯 核心目标                         │
│  [一句话概括文档目的]                 │
├─────────────────────────────────────┤
│  💡 关键结论（3-5条）                 │
│  • 结论1                            │
│  • 结论2                            │
│  • 结论3                            │
├─────────────────────────────────────┤
│  📊 重要数据                         │
│  [关键数字、百分比、对比]             │
├─────────────────────────────────────┤
│  ✅ 行动项                           │
│  [谁 + 做什么 + 何时]                │
├─────────────────────────────────────┤
│  📎 原文链接/附件                     │
└─────────────────────────────────────┘
```

### 多文档汇总
将多份相关文档整合为一份摘要：
- 统一格式和术语
- 去重合并相似内容
- 标注信息来源
- 生成对比表格（如多方案对比）

### 联网信息整合
文档需要引用最新外部信息时，优先使用当前 Codex 会话提供的网页搜索/浏览能力，并打开原始来源。
获取的信息必须标注来源和获取时间；当前会话不能联网时，只使用用户材料并保留待核验标记。

## 白板设计规范

### 流程图
- 使用标准符号：矩形（过程）、菱形（判断）、椭圆（起止）
- 箭头方向清晰，避免交叉
- 配色简洁，不超过 3 种主色

### 思维导图
- 中心主题突出
- 分支层级清晰
- 关键词而非长句
