# Codex / 产品界面皮肤设计

Translate a visual brief into a coherent interface skin that can be implemented in the actual product. First identify the target surface, supported customization points, and any screenshots or theme files. Do not assume Codex exposes a public skin API; if the user means Codex Desktop itself, distinguish supported settings from a mockup or an unsupported modification.

Deliver a compact design specification: reference direction, color tokens with accessible text/background contrast, typography, spacing, surfaces, controls, states, and representative screen examples. Keep the visual system consistent across light/dark modes where relevant. For a working implementation, inspect the target app and edit its real theme or CSS; for a concept request, provide a clearly labeled mockup/spec. Do not claim to have installed a theme when only a visual concept was produced.
