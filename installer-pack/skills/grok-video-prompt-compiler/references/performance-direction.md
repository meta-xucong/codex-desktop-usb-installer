# 表演与情绪规划

只在人物心理、对白或互动情绪需要作为成片交付时读取本文件。目标不是让模型猜一个情绪词，而是把原文意图变成能在画面和声音中验收的表演关系。

## LLM 提炼流程

1. 找出来源中的可观察证据：动作、停顿、关系变化、措辞、前后行为。不要复述整段原文，也不要输出隐藏推理。
2. 为每个核心角色选择一个短弧：起始状态、触发转折、结尾状态。状态必须能被镜头看见，例如克制的防备、试探后的放松，而不是抽象的情绪强度。
3. 对每句关键对白写潜台词、声线和可见提示。潜台词回答角色为什么此刻这样说；声线说明音量、呼吸、节奏或尾音；可见提示说明眼神、肩膀、手或停顿。
4. 写一到三个禁止误读，优先排除最可能破坏原意的相近演法。禁止误读必须针对本镜，不要变成全局的负面词。
5. 为需要互动的对白写听者反应。一个角色说话、另一个角色静止倾听或作出明确回应，比两个角色同时做复杂动作更容易保住情绪。

## 编排规则

- 关键台词要有独占表演窗口：嘴部可见，不与接吻、走路、转身、切镜或其他人说话重叠。
- 一句关键台词通常只承载一个情绪转折。多句关键台词、走位和道具交接集中在短片段时，优先拆镜头，不用慢动作填时长。
- 把情绪翻译为行为，不要只写害羞、伤心、深情、愤怒。例如，克制的尴尬可以是一次短促吸气、目光暂避后回望、说完轻轻松开衣角。
- 不把角色关系预设为单人或双人。只有原文和本镜需要时才写互动、听者反应、肢体接触或镜头距离。
- 表演约束与连续性锚点职责不同：前者控制情绪含义，后者控制手、道具、位置和接触关系。两者同时需要时分别声明。

## Prompt 与验收

编译器只将 `critical` 和 `important` 的弧与对白节拍写入 Prompt，避免环境情绪挤占动作、身份或道具预算。它会在报告中保留 `performance_plan`，并在关键对白过密、缺少禁止误读或缺少听者反应时给出建议。

验收至少检查：

- 台词是否逐字可辨、嘴形可见且没有被其他动作遮挡。
- 声线、停顿、眼神和肢体是否呈现声明的潜台词。
- 是否落入 `forbidden_readings` 中的错误情绪。
- 听者反应是否支持而非冲淡说话者的情绪。

如果台词字面正确但情绪、口型或听者反应失败，保留已验收的画面并只替换该对白的配音/口型，或重做只承载该对白的短镜头；不要直接重复原任务。
