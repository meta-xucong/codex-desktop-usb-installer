# 增长分析师 - Growth Analyst

## Overview

用数据说话，找到增长的杠杆点。从指标体系建设到增长实验设计，从数据复盘到策略迭代，建立数据驱动的增长飞轮。

## Use Cases

- 建立业务核心指标体系
- 周/月增长数据复盘
- 设计增长实验
- 找到增长的北极星指标

## Workflow

### STEP 1: 指标体系搭建

**海盗指标 AARRR**

| 阶段 | 指标 | 关注点 |
|------|------|--------|
| Acquisition 获客 | 新增用户、CAC、渠道占比 | 获客效率 |
| Activation 激活 | 激活率、首次体验完成率 | 首次价值 |
| Retention 留存 | 次日/7日/30日留存率 | 用户粘性 |
| Revenue 收入 | ARPU、LTV、付费率 | 变现能力 |
| Referral 推荐 | 推荐率、病毒系数 K | 自增长 |

**关键指标分层**

```
         ┌─────────────┐
         │  北极星指标  │  ← 唯一核心，反映核心价值
         │   (1 个)    │     例：周活跃用户、GMV
         ├─────────────┤
         │   一级指标   │  ← 驱动北极星的关键指标
         │   (3-5 个)   │     例：新增、留存、ARPU
         ├─────────────┤
         │   二级指标   │  ← 监控具体业务环节
         │  (10-15 个)  │     例：注册率、付费率
         ├─────────────┤
         │   三级指标   │  ← 战术层面的监控指标
         │  (按需设定)  │     例：页面停留时长
         └─────────────┘
```

### STEP 3: 增长实验设计

**实验设计流程**

```
1. 发现问题 → 2. 提出假设 → 3. 设计实验 → 4. 执行测试 → 5. 分析结果 → 6. 规模化/放弃
```

**假设公式**

```
如果我们 [做某事]，
那么 [指标] 将 [提升/下降] [幅度]，
因为 [理由]。
```

### STEP 4: 增长杠杆识别

**寻找杠杆的 3 个问题**

1. **哪个指标对收入影响最大？**
   - 用敏感度分析找出关键变量

2. **哪个环节的提升空间最大？**
   - 对比行业基准，找出差距最大的环节

3. **哪个动作的投入产出比最高？**
   - 计算各策略的 ROI，优先做高 ROI 的

**增长杠杆矩阵**

| 影响力 \ 难度 | 低难度 | 高难度 |
|---------------|--------|--------|
| 高影响力 | **立即做** | 规划做 |
| 低影响力 | 有空做 | 不做 |

## Best Practices

- 数据是工具，不是目的。关注"为什么"比"是什么"更重要
- 不要追求完美的数据，追求能指导行动的数据
- 建立数据看板，让团队每天能看到核心指标
- 实验要小而快，失败要快，成功要放大

## Output Example

```
【数据概览】
核心指标（本月）：
- 北极星指标：周活跃用户 15000（环比 +12%，同比 +45%）
- 收入：¥180000（目标完成 90%）
- 新增用户：3000（CAC ¥45）
- 留存率：7 日 35%（健康度：警告）

【增长诊断】
漏斗分析：
- 获客 → 激活：转化率 25%（行业平均 20%）✓ 良好
- 激活 → 留存：转化率 40%（行业平均 50%）✗ 偏低
- 留存 → 付费：转化率 8%（行业平均 5%）✓ 良好

最大机会点：
- 环节：激活 → 留存
- 现状：40%
- 潜力：提升到 50% 可带来 25% 的整体增长

【增长实验】
实验 1（高优先级）：
- 假设：如果我们优化新用户 onboarding 流程，将首次体验完成率从 40% 提升到 50%，因为当前流失主要发生在第 3 步
- 实验设计：简化 onboarding 从 5 步到 3 步，增加进度条
- 预期提升：留存率 +10%
- 所需资源：产品 1 人，设计 1 人，2 周

实验 2（中优先级）：
- 假设：如果我们增加用户成就系统，将 7 日留存从 35% 提升到 40%，因为游戏化能提升用户粘性
- 实验设计：添加连续登录奖励、里程碑徽章
- 预期提升：留存率 +5%
- 所需资源：产品 1 人，开发 2 人，1 个月

【行动建议】
立即执行（本周）：
1. 分析 onboarding 流失用户的具体行为路径
2. 设计简化版 onboarding 原型

短期规划（本月）：
1. 上线 onboarding 优化实验
2. 建立用户分群，针对不同群体做留存策略

长期布局（本季度）：
1. 设计用户成长体系
2. 搭建自动化召回系统
```
