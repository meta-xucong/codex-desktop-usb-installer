# 小红书笔记写作 Skill

帮助用户写出清楚、可信、符合目标受众与指定语气的小红书文案；不承诺曝光、点击、互动或转化效果。

---

## ⚠️ 重要：去AI味检查（写之前必看）

AI生成的文本有明显特征，一眼就能看出来。写小红书笔记时，**必须避免**以下问题：

### 🚫 常见的12种机械表达

#### 致命特征（一眼AI）
| 问题 | AI写法 | 人类写法 |
|------|--------|----------|
| 三段式结构 | "首先...其次...最后..." | 直接说事，不用套路 |
| 机械连接词 | "值得注意的是"、"综上所述"、"不难发现" | "说实话"、"其实"、"真的" |
| 空洞大词 | "赋能"、"闭环"、"数字化转型"、"智慧时代" | "帮忙"、"完整流程"、"升级" |
| 均匀段落 | 每段都差不多长 | 长短不一，有节奏感 |

#### 高频问题
| 问题 | 表现 |
|------|------|
| AI高频词 | "助力"、"彰显"、"凸显"、"焕发"、"深度剖析" |
| 修辞堆砌 | 对偶句>2个、排比句>1个、引用句>4个 |
| 技术词滥用 | 在非技术内容里用"解构"、"光谱"、"量子纠缠" |
| 标点滥用 | 破折号太多、分号太密 |

#### 风格问题
| 问题 | 表现 |
|------|------|
| 句子太规整 | 每句话结构都差不多 |
| 用词单一 | 来回就那几个词 |
| 没情绪 | 整篇都很"平"，没有喜怒哀乐 |
| 开头重复 | 每段开头都是"这个..."、"那..." |

### ✅ 人类化重写规则

```
1. 去掉"首先其次最后" → 直接说事
2. "值得注意的是" → "注意" / "说真的"
3. "综上所述" → "所以" / "总之"
4. "赋能" → "帮" / "让...更好"
5. 打破均匀段落 → 长短搭配
6. 只有用户提供相应真实经历时才使用第一人称，如“我觉得”或“亲测”；不得代编体验
7. 句子长短不一 → 有短有长
8. 适当"不完美" → 口语化、有语气词
```

## 🦞 小红书风格参考

可选择朋友聊天式语气；具体表达由用户的受众、内容和目标决定。

### 可选风格提示
- ✅ **开场** - 按受众和语气选择称呼；不确定时直接切入主题
- ✅ **emoji** - 用户需要或适合该语气时少量使用
- ✅ **短段落** - 1-3句话一段，别写长文
- ✅ **口语化** - 像说话，不像写论文
- ✅ **个人视角** - 仅采用用户提供的身份和经历；缺失时保持中性叙述
- ✅ **情绪词** - 只在符合用户语气且有事实依据时使用

### 绝对禁止
- ❌ "首先、其次、最后"的三段式
- ❌ "值得注意的是"、"综上所述"
- ❌ 大段文字（超过5行就太长）
- ❌ 用户明确要求克制、正式或不使用 emoji 时仍强行加入表情
- ❌ 像说明书一样的列表

## 🚀 使用流程

### 第一步：了解需求
收集用户已提供的主题、受众、语气、篇幅和目标。只询问会实质影响成稿且无法合理默认的信息；用户只要标题时，仅生成标题。不得强制追问完整 brief。

### 第二步：生成标题
按用户目标生成标题备选。数字、效果、排名、身份或时限只有在用户提供或可核验来源支持时才可写；缺证据时改为中性表达或注明占位。涉及自身经历时，必须来自用户提供并确认可公开的真实材料。

### 第三步：写正文
1. 按用户目标选择结构或开头；不需要模板时直接写
2. 使用符合用户指定语气的表达
3. 只有适合内容或用户要求时才加入 emoji 和情绪词
4. 根据篇幅和阅读场景调整段落

### 第四步：去AI味检查
对照上面的常见表达问题，按需检查并修改。

### 第五步：输出成品
- 按用户要求提供标题备选；未指定时可给 3 个
- 需要正文时再提供正文
- 只有用户需要时提供相关标签

## 🎯 标题写作公式（创意建议，不保证效果）

### 7种常见标题思路

#### 1. 目标型（描述用户目标，不保证结果）
```
公式：行动 + 主题或可核验的预期结果
示例：
- "把这个习惯坚持下来：我的记录方式"（仅用户提供真实记录时使用第一人称）
- "想改善穿搭质感？先试试这套搭配思路"
- "按计划运动：一份可调整的训练安排"
```

#### 2. 常见疑问型
```
公式：常见疑问 + 清晰主题（避免制造无依据的紧迫感）
示例：
- "护肤成分怎么看：先读产品说明和可靠资料"
- "容易忽略的省钱细节：先看这几项"
- "洗脸常见误区：这些说法先核对来源"
```

#### 3. 数字型（具体可信）
```
公式：数字 + 核心内容（数字准确且有依据时才使用）
示例：
- "日常妆容的几个步骤：按个人需求调整"
- "整理几种穿搭搭配思路，按衣橱情况选择"
- "初秋穿搭搭配思路：结合天气和个人偏好"
```

#### 4. 误区澄清型（需有可靠依据）
```
公式：问题或常见误区 + 可核验的信息
示例：
- "护肤步骤常见疑问：先核对产品说明"
- "使用产品前，先确认适用方法和注意事项"
- "护肤成分怎么读？先分清宣传与证据"
```

#### 5. 提问型（引发好奇）
```
公式：问题 + 痛点
示例：
- "哪些因素会影响妆容持久度？"
- "小个子怎么穿才显高？"
- "护肤产品怎么比较？先看成分与适用说明"
```

#### 6. 参考对象型
```
公式：公开参考对象 + 可观察的特点（需准确描述）
示例：
- "拆解一套公开穿搭：看看配色和廓形怎么搭"
- "拆解公开妆容造型：观察配色与线条"
- "AI入门路线：把基础内容拆成几个小步骤"
```

#### 7. 相关人群型
```
公式：相关人群 + 主题或可核验的信息
示例：
- "学生党选护肤品：先看预算和产品说明"
- "新手爸妈可参考的睡前流程：结合自家情况调整"
- "工程师学AI：从一个基础问题开始"（只有用户确认身份后才使用职业标签）
```

### 万能标题公式

```
主题 + 读者相关信息 + 解决思路

示例：
- "毛孔护理怎么做？先看适用条件与可靠来源"
- "小个子穿搭｜这组比例搭配思路供参考"
- "AI入门路线：从基础概念到一个小练习"
```

### 五大品类标题公式

| 品类 | 公式 | 示例 |
|------|------|------|
| 穿搭 | 场景 + 搭配思路 | "小个子通勤穿搭：这组比例思路供参考" |
| 美妆 | 需求 + 产品或成分信息 | "选口红先看什么：色调、质地和试色条件" |
| 母婴 | 具体问题 + 可参考的信息 | "宝宝睡前流程怎么安排：按家庭情况调整" |
| 美食 | 场景 + 菜品或做法 | "一人食晚餐：番茄鸡蛋面的做法记录" |
| 干货/知识 | 主题 + 解释或步骤 | "机器学习入门：用三个问题梳理基础" |

## 📝 开头参考（5种，可按需取用）

### 1. 打招呼式（可选）
```
像老朋友聊天一样

✅ 好的写法：
"今天聊聊这个主题。"
"如符合用户指定语气，也可以用简短称呼开场。"

❌ AI写法：
"大家好，今天我想和大家分享..."
```

### 2. 与我相关型（引发共鸣）
```
让读者觉得"这说的就是我"

✅ 好的写法：
"身高____、体型____，我尝试了____"（只填入用户提供并确认可公开的事实）
"作为____，我遇到过____"（仅在用户提供并确认可公开时填写）
"如果你也在关注____，这篇整理了相关信息。"

❌ AI写法：
"作为一个____，我想分享一下我的经验..."
```

### 3. 主题切入型
```
直接点出读者的困扰

✅ 好的写法：
"如果你在关注AI入门，可以先从基础概念开始梳理。"
"如果你在关注____，可以先了解这些基础信息。"
"如果你最近经常加班，可以看看这些时间安排思路。"

❌ AI写法：
"很多人都会遇到这样的问题：____"
```

### 4. 提示型（信息有依据时）
```
✅ 好的写法：
"正在学AI？这里整理了几个常见问题供核对。"
"编程入门前，可以先了解这些基础概念。"
"关于____，可以先确认适用条件和资料来源。"

❌ AI写法：
"以下是一些需要注意的事项..."
```

### 5. 近期话题型（需核实信息）
```
✅ 好的写法：
"最近在关注____？这里整理了相关基础信息。"
"涉及近期热点时，先核对事件和发布日期。"

❌ AI写法：
"随着xx的发展，越来越多的人开始关注..."
```

## 📝 示例输出格式

以下机器学习示例为通用教学文案，不声称作者有个人学习经历或职业资质。

### ❌ 模板化写法示例

```
【标题】机器学习的三层理解

【正文】

大家好，今天我想和大家分享一下我对机器学习的理解。

首先，我想介绍一下函数层。函数层是机器学习的基础，它定义了模型的结构。

其次，损失层非常重要。它决定了我们如何衡量模型的好坏。

最后，优化层是让模型不断改进的关键。

综上所述，这三层结构帮助我们理解机器学习的本质。

【标签】#机器学习 #AI
```

### ✅ 更自然的写法参考

```
【标题备选】
1. 机器学习三层框架：从函数到优化🧠
2. 机器学习别急着背概念：先看这三个层次🔥
3. 机器学习入门｜用三个问题梳理基础✨

【正文】

学机器学习时，概念容易显得又多又散。神经网络、梯度下降、损失函数各有用途，可以先用三个层次梳理：**函数、损失、优化**。

不多废话，直接说：

---

### 🧱 第一层：函数层（Model）

**模型长啥样？**

就是在找一个 **f(x)**

- 线性回归：就是 y = wx + b（高中数学对吧）
- 神经网络：就是好多 wx+b 叠在一起
- 决策树：就是一堆 if-else

别被名字吓到，本质上都是**函数**。

---

### 📉 第二层：损失层（Objective）

**怎么判断模型好不好？**

先定义单样本损失 **L**（比如分类用交叉熵，回归用MSE）

然后汇总成目标函数 **J(θ)**

**关键来了：J(θ) 决定了优化的方向！**

就像开车，你得先知道目的地在哪，才能往那边开对吧。

---

### 🎯 第三层：优化层（Optimization）

**怎么让模型越来越好？**

就是不断调整 θ，让 J(θ) 变小。

方法很多：
- 梯度下降（神经网络标配）
- 贪心分裂（决策树）
- Boosting（XGBoost、LightGBM）

说白了就是：**下山怎么走最快？**

---

### 💡 所以呢？

以后学任何新模型，就问自己3个问题：
1. f(x) 是什么？（函数层）
2. L 和 J(θ) 是什么？（损失层）
3. 怎么更新 θ？（优化层）

这些问题可帮助梳理概念；不应据此判断学习者是否“真正理解”。

---

如果这种拆分方式对你有帮助，可以收藏。也欢迎补充你想看的概念。

【建议标签】
#机器学习 #AI学习 #学习笔记 #入门知识
```
