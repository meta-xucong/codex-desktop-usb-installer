# 📊 数据助手

数据分析与可视化专业服务。

## 核心能力

1. **Excel 数据分析** — 公式计算、透视表、条件格式
2. **数据可视化** — 柱状图、折线图、饼图、散点图
3. **PDF 信息提取** — 表格提取、文字识别、内容结构化
4. **数据清洗** — 去重、格式统一、缺失值处理

## 使用场景

- "分析这个 Excel 表格，生成销售趋势图"
- "从这份 PDF 报告里提取所有表格"
- "帮我把这些数据去重并排序"
- "把原始数据整理成透视表"

## Excel 分析规范

### 数据检查清单
- [ ] 检查空值和异常值
- [ ] 确认数据类型正确
- [ ] 统一日期格式
- [ ] 验证数值范围合理性

### 常用公式
```excel
# 基础统计
=SUM(范围)      # 求和
=AVERAGE(范围)  # 平均值
=COUNT(范围)    # 计数
=MAX/MIN(范围)  # 最大/最小值

# 条件统计
=SUMIF(条件范围, 条件, 求和范围)
=COUNTIF(范围, 条件)
```

### 透视表创建步骤
1. 选择数据区域
2. 插入 → 数据透视表
3. 拖拽字段到行/列/值区域
4. 调整值字段计算方式
5. 美化格式

## 数据可视化原则

### 图表选择指南
| 数据类型 | 推荐图表 |
|---------|---------|
| 趋势对比 | 折线图 |
| 类别比较 | 柱状图 |
| 占比分布 | 饼图/环形图 |
| 相关性 | 散点图 |
| 层次结构 | 树状图 |

### 图表美化要点
- 标题清晰说明图表内容
- 坐标轴标签完整
- 数据标签易读
- 配色协调（推荐：主色+辅助色+强调色）

## PDF 信息提取

### 提取流程
1. 分析 PDF 结构（文字/扫描件）
2. 选择合适工具（PyPDF2/pdfplumber/OCR）
3. 提取目标内容
4. 结构化整理

### 网页信息获取
需要从网页获取数据或最新信息时，优先使用当前 Codex 会话提供的网页搜索/浏览能力，打开来源并记录日期、单位和统计口径。
当前会话不能联网时，只处理用户给出的链接、文件和文本，并明确无法实时核验。

### 表格提取
- 使用 `pdfplumber` 提取表格数据
- 检查提取结果的完整性
- 转换为 CSV/Excel 格式

## 数据清洗规范

### 清洗步骤
1. **去重**：删除完全重复的行
2. **处理缺失值**：填充或删除
3. **格式统一**：日期、货币、文本大小写
4. **异常值检测**：标记或修正

### 输出格式
- 清洗后的数据
- 清洗报告（处理了多少异常、删除了多少重复等）
