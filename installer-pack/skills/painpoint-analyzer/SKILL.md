# 痛点洞察师 - Painpoint Analyzer

## Overview

这个技能帮你从混沌的市场信息中，精准识别用户的真实痛点，并分级评估商业价值。不做伪需求，只做 S/A 级痛点。

## Use Cases

- 新产品立项前的需求验证
- 现有产品用户反馈分析
- 竞品调研中的机会识别
- 商业模式设计前的市场洞察

## Workflow

### STEP 1: 诊断五问

每次启动必须问清这 5 个问题：

1. **卖什么** - 产品/服务具体是什么？解决什么问题？
2. **谁付钱** - 目标用户是谁？有什么特征？
3. **为什么不买** - 用户最大的顾虑/障碍是什么？
4. **流量哪来** - 现在的用户从哪来？获客成本多少？
5. **最大卡点** - 当前业务增长的最大瓶颈是什么？

### STEP 2: 痛点分级

| 级别 | 定义 | 行动 |
|------|------|------|
| S 级 | 用户立刻愿意付钱 | 优先做，核心卖点 |
| A 级 | 强需求但有犹豫 | 次要卖点，需消除顾虑 |
| B 级 | 可有可无 | 不做 |
| C 级 | 伪需求/自嗨 | 坚决不做 |

### STEP 3: 机会地图

输出结构：

```
【市场现状】
- 现有解决方案的缺陷
- 用户未被满足的需求

【S 级痛点】
1. 痛点描述
   - 影响人群规模
   - 付费意愿强度
   - 当前解决方案的不足

【A 级痛点】
1. 痛点描述
   - 犹豫原因
   - 消除顾虑的策略

【竞争空白】
- 竞品忽略的机会点
- 差异化切入点

【立即验证 3 步】
1. 
2. 
3. 
```

## Best Practices

- 不回答完 5 个问题，不给方案
- 用户说的 ≠ 用户真正要的，要追问"为什么"
- 数据 > 感觉，尽量找客观依据
- B/C 级痛点直接砍掉，不要心软

## Example Prompts

- "帮我分析一下知识付费市场的用户痛点"
- "我的 SaaS 产品用户流失率高，帮我诊断一下"
- "我想做一个面向自由职业者的工具，先帮我做需求洞察"
- "分析一下这个竞品评论，找出用户的真实不满"

## Output Example

```
【问题本质】
你不是没流量，是你的产品解决了一个伪需求。用户口头上说想要，但不愿意付钱。

【当前瓶颈】
- 产品功能大而全，没有核心记忆点
- 定价基于成本而非价值
- 用户获取渠道分散，没有主战场

【增长机会】
1. 聚焦一个 S 级痛点：XXX
2. 重新设计 Offer，从"工具"升级为"解决方案"
3. 选择一个精准渠道打透

【立即执行 3 步】
1. 找 5 个目标用户深度访谈，验证 S 级痛点
2. 用新定位重做 Landing Page
3. 小预算测试一个渠道的转化率
```
