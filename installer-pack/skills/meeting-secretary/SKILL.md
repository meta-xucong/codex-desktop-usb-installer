# 📝 会议秘书

专业会议纪要与议程管理服务。

## 核心能力

1. **会议纪要整理** — 速记文字 → 结构化纪要
2. **待办提取** — 识别行动项、负责人、截止日期
3. **议程规划** — 设计会议流程、时间分配
4. **会议准备** — 资料整理、参会人通知模板

## 使用场景

- "把这次会议速记整理成正式纪要"
- "从会议记录里提取所有待办事项"
- "帮我设计下周评审会的议程"
- "生成会议邀请邮件模板"

## 会议纪要结构

### 标准模板
```markdown
# [会议主题]

## 基本信息
- **时间：** YYYY-MM-DD HH:MM - HH:MM
- **地点：** 
- **主持人：**
- **记录人：**
- **参会人：**

## 议程与讨论

### 议题 1：[议题名称]
**讨论内容：**
- 要点 1
- 要点 2

**决议：**
- 决议内容

### 议题 2：[议题名称]
...

## 行动项

| 序号 | 事项 | 负责人 | 截止日期 | 状态 |
|-----|------|--------|---------|------|
| 1 | | | | 待开始 |

## 下次会议
- **时间：**
- **议题：**
```

## 待办提取规范

### 识别关键词
- 行动词："负责"、"跟进"、"确认"、"准备"、"完成"
- 时间词："明天"、"下周"、"月底前"、"周五前"
- 责任人："@姓名"、"由...负责"

### 待办事项格式
```markdown
- [ ] [具体行动] — @[负责人] [截止日期]
```

### 优先级标记
- 🔴 高优先级：当天或次日完成
- 🟡 中优先级：本周内完成
- 🟢 低优先级：下周或更晚

## 议程设计原则

### 时间分配
| 会议类型 | 建议时长 | 议程数量 |
|---------|---------|---------|
| 站会 | 15 分钟 | 3-4 项 |
| 周会 | 30-60 分钟 | 4-6 项 |
| 评审会 | 60-90 分钟 | 3-5 项 |
| 战略会 | 2-4 小时 | 2-4 大议题 |

### 议程结构
1. **开场**（5%）：目的说明、规则确认
2. **回顾**（10%）：上次行动项检查
3. **核心议题**（70%）：讨论与决策
4. **总结**（10%）：决议确认、待办梳理
5. **结束**（5%）：下次安排、散会

## 会议掌控与时间控制

### 会议主持人控场指南

**开场（2分钟）：**
- 说明会议目的和预期产出
- 确认议程和时间安排
- 约定发言规则（如：不打断、聚焦主题）

**进行中：**
- **时间提醒**：每议题剩5分钟时提醒
- **偏题拉回**："这个点很重要，建议会后再详细讨论"
- **沉默打破**："我想听听[某人]的看法"
- **争议处理**："双方观点都有道理，建议先记录，会后专题讨论"

**收尾（3分钟）：**
- 总结决议和行动项
- 确认下次会议安排
- 感谢参会

### 时间控制工具

**议程计时表：**
```
议题              计划时间    实际用时    状态
─────────────────────────────────────────
开场              2分钟       2分钟       ✅
议题1：XX         15分钟      18分钟      ⚠️ 超时3分
议题2：XX         15分钟      12分钟      ✅ 提前3分
总结              3分钟       3分钟       ✅
─────────────────────────────────────────
总计              60分钟      58分钟      ✅
```

**控场话术：**
- 时间到："时间关系，我们先记录这个结论，继续下一个议题"
- 跑题："这个点很有价值，建议单独安排讨论"
- 争执："双方观点都记录了，建议会后评估可行性"
- 沉默："这个问题比较复杂，[某人]你怎么看？"

## 会议准备清单

### 会前准备
- [ ] 确定会议目的和预期产出
- [ ] 设计议程并分配时间
- [ ] 准备相关资料
- [ ] 发送会议邀请（提前 24 小时）
- [ ] 确认参会人时间
- [ ] 准备计时工具（手机/计时器）

#### 背景资料搜索
如需准备行业背景或竞品信息，优先使用当前 Codex 会话提供的网页搜索/浏览能力，并记录来源和检索日期。
当前会话不能联网时，只使用用户给出的材料并把缺失信息列为待确认项。

### 会中记录要点
- 决策结论（而非讨论过程）
- 具体数字和时间
- 明确的行动项（谁+做什么+何时）
- 争议点和待确认事项
- 实际用时（用于优化下次议程）

### 会后跟进
- [ ] 24 小时内发送纪要
- [ ] 同步行动项到任务管理工具
- [ ] 跟踪关键待办进度
- [ ] 收集会议反馈（可选）
