# Offer 设计师 - Offer Designer

## Overview

把产品从"功能清单"升级为" irresistible offer（无法拒绝的提案）"。解决"卖什么、怎么卖、卖多少钱"的核心问题。

## Use Cases

- 新产品定价与包装
- 现有产品重新定位
- 设计高转化销售页面
- 构建产品矩阵与 upsell 路径

## Workflow

### STEP 1: 价值锚定

明确 3 个核心问题：

1. **结果价值** - 用户购买后能得到什么具体结果？
2. **情感价值** - 用户购买后感觉如何？（身份认同、安全感、成就感）
3. **社会价值** - 用户购买后在他人眼中如何？

### STEP 2: Offer 结构设计

核心公式：**Offer = 核心产品 + 超级赠品 + 风险逆转 + 稀缺性**

| 组件 | 说明 | 示例 |
|------|------|------|
| 核心产品 | 解决核心痛点的主体 | 课程、工具、服务 |
| 超级赠品 | 提升感知价值 | 模板库、社群、1v1 |
| 风险逆转 | 消除购买顾虑 | 退款保证、试用期 |
| 稀缺性 | 促成立刻行动 | 限时、限量、涨价 |

### STEP 3: 定价策略

三种定价模型：

**成本加成法**（不推荐，但要知道）
- 成本 × (1 + 利润率)
- 问题：忽略了用户感知价值

**价值定价法**（推荐）
- 基于用户获得的价值定价
- 公式：价格 = 用户获得价值 × 10%~30%

**竞争定价法**（参考）
- 对标竞品，略高或略低
- 必须有明确的差异化支撑

## Best Practices

- 定价基于价值，不是成本
- 赠品要"看起来贵，做起来便宜"
- 风险逆转要真实可信，不要假承诺
- 稀缺性必须是真实的，否则就是欺骗

## Example Prompts

- "帮我设计一个在线课程的 Offer，目标用户是职场新人"
- "我的 SaaS 产品定价太低了，帮我重新设计定价策略"
- "设计一个引流款 + 利润款的产品矩阵"
- "帮我优化这个销售页面的 Offer 结构"

## Output Example

```
【产品定位】
一句话定位：我们是职场新人的「升职加薪加速器」，帮助 0-3 年职场人快速建立核心竞争力，实现 1 年内薪资翻倍
差异化标签：不教理论，只给能直接用的模板和话术

【Offer 结构】
核心产品：《职场加速器》21 天训练营
- 交付：12 节视频课 + 每日作业 + 社群答疑
- 形式：录播 + 直播答疑 + 社群陪伴

超级赠品：
1. 价值 999 元的「升职加薪话术库」（50+ 场景模板）
2. 价值 1999 元的「1v1 简历诊断」一次
3. 价值 499 元的「职场人脉资料包」

风险逆转：7 天无理由退款，学完第一节不满意全额退

稀缺性：前 100 名早鸟价，满员后涨价 200 元

【定价策略】
建议定价：¥999（早鸟价 ¥799）
定价逻辑：用户实现一次薪资谈判成功，平均涨薪 3000+/月，ROI 超过 30 倍
价格锚点：原价 ¥1999，限时 ¥799

【产品矩阵】
- 引流款：《职场新人避坑指南》电子书（¥9.9）
- 利润款：《职场加速器》训练营（¥799）
- 高端款：1v1 职场导师服务（¥4999/月）
```
