# Canvas 状态

本目录保留了原始能力的名称，当前在 Codex 能力包中标记为 `unsupported/disabled`。
它依赖特定宿主应用的远程节点画布、设备桥接和专用页面路由；这些接口不属于 Codex
技能目录，也不会被本安装包伪装成可用功能。

## 替代方式

- 需要生成 HTML、仪表盘或交互原型时，直接在工作区创建文件。
- 需要预览时，使用 Codex 的文件预览、浏览器或本地开发服务器能力（如果当前环境提供）。
- 需要手机或远程设备展示时，请另行配置对应的浏览器/设备连接工具。

## 能力边界

本技能不会启动远程网关、连接移动设备、修改主机配置，也不会声称已经把页面推送到外部设备。
