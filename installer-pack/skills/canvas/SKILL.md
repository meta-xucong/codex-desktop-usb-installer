# Canvas 能力边界

本 Skill 会随安装包复制并在配置层面默认启用，但它不捆绑外部 Canvas 节点、远程画布
网关或设备桥接服务。调用时必须先确认外部后端已连接；后端不存在、探针失败或权限不足时，
明确返回“Canvas 后端未连接/能力不可用”，不伪造已经创建、预览或推送外部画布的结果，也不得省略缺失后端。

## 可用方式

- 需要生成 HTML、仪表盘或交互原型时，直接在工作区创建文件；这是本地可用的降级路径。
- 需要预览时，使用 Codex 的文件预览、浏览器或本地开发服务器能力（如果当前环境提供）。
- 需要手机或远程设备展示时，请另行配置对应的浏览器/设备连接工具。

## 外部后端缺失时

本技能不会自行启动远程网关、连接移动设备、修改主机配置，也不会伪造外部操作结果。
请说明缺少的依赖：`external.host-specific-canvas-runtime`，并给出本地 HTML 文件作为替代产物。
