# 竞品情报分析

系统化竞品对标与策略解码框架，帮助识别竞争态势与差异化机会。

## 分析维度

### 1. 竞品识别与筛选

**直接竞品**：解决相同问题、面向相同客群
**间接竞品**：解决相同问题、不同客群或方案
**潜在竞品**：可能进入市场的跨界玩家

**筛选标准**：
- 市场份额前3-5名
- 近期获得融资或快速增长
- 用户口碑较好或争议较大
- 与自身产品有直接竞争关系

### 2. 功能矩阵对比

**对比框架**：

| 功能维度 | 我方 | 竞品A | 竞品B | 竞品C |
|---------|------|-------|-------|-------|
| 核心功能1 | ✓ | ✓ | ✓ | ✗ |
| 核心功能2 | ✓ | ✗ | ✓ | ✓ |
| 差异化功能 | ✓ | ✗ | ✗ | ✗ |

**分析要点**：
- 功能完备度对比
- 用户体验差异
- 技术实现路径
- 创新功能识别

### 3. 定价策略解码

**分析维度**：
- 定价模式（订阅/按量/买断/免费增值）
- 价格区间与档位设计
- 付费转化路径
- 折扣与促销策略

**关键指标**：
- ARPU（每用户平均收入）
- 付费率估算
- 客单价区间

### 4. 商业模式分析

**分析框架**：
- 价值主张
- 收入来源
- 成本结构
- 关键资源
- 渠道通路

### 5. 市场定位研判

**定位地图**：
- 价格轴（高端-低端）
- 功能轴（全面-专注）
- 客群轴（企业-个人）

**空白机会识别**：未被满足的市场空间

## 数据来源

优先使用当前 Codex 会话提供的网页搜索/浏览能力，并为会变化的信息记录来源与日期。如果网页能力不可用，
只使用用户提供的材料并标注证据缺口；不得把推测写成已核验事实。

- 官网与公开产品资料
- App Store、社区和公开用户评价
- 行业报告与新闻
- 公开招聘动态
- 社交媒体与公开社区讨论

## 注意事项

- 保持客观，避免主观偏见
- 区分事实与推测
- 关注动态变化，定期更新
- 保护商业机密，合规获取信息
