# 设备连接边界

本 Skill 会随安装包复制并在配置层面默认启用，但它不捆绑设备配对协议、远程网关或节点后端。
调用时必须以实际配对探针为依据；后端未连接、协议不兼容或认证失败时，明确返回“设备连接后端
不可用/未配对”，不伪造已配对结果，也不得把网页可达、二维码生成或静态配置当成配对。

诊断应限定于用户指定的设备、目标地址和所述症状。不要为了排查配对问题而枚举整机进程、服务、环境变量、监听端口或通用配置；只有用户明确要求且该检查与目标直接相关时，才读取最少必要的信息，并先过滤凭据和无关个人数据。不得复述 access token、API key、密码或完整敏感配置。

## 可用替代

对于普通浏览器或局域网服务连接，可检查目标地址、端口、网络隔离、防火墙和身份认证；
对于手机自动化，请安装并配置明确的浏览器/设备连接工具，再由对应工具提供诊断信息。

用户询问网页是否正常显示时，应将“网络可达”和“页面视觉状态”分开：只有当前会话确实有权使用且可用的浏览器/截图工具时才检查页面画面；没有该工具或目标不可访问时，明确说明无法直接观察，并请用户提供截图或页面错误信息。不能只凭地址能打开就断言页面显示正常，也不能把网页检查当成设备配对探针。

不得把“能访问网页”或“二维码已生成”误报为设备已经配对。外部依赖名称：
`external.device-pairing-runtime`。
