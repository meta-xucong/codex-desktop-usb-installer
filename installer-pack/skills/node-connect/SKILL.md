# 设备连接边界

本 Skill 会随安装包复制并在配置层面默认启用，但它不捆绑设备配对协议、远程网关或节点后端。
调用时必须以实际配对探针为依据；后端未连接、协议不兼容或认证失败时，明确返回“设备连接后端
不可用/未配对”，不伪造已配对结果，也不得把网页可达、二维码生成或静态配置当成配对。

## 可用替代

对于普通浏览器或局域网服务连接，可检查目标地址、端口、网络隔离、防火墙和身份认证；
对于手机自动化，请安装并配置明确的浏览器/设备连接工具，再由对应工具提供诊断信息。

不得把“能访问网页”或“二维码已生成”误报为设备已经配对。外部依赖名称：
`external.device-pairing-runtime`。
