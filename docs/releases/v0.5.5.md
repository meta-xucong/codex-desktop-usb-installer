# Codex App Manager v0.5.5

## MSIX 卸载兼容性修复

本版修复部分旧版/普通 sideload MSIX 卸载时的 `0x80073CFA`：Windows
虽然暴露了 `Remove-AppxPackage -PreserveApplicationData` 参数，但对不是由部署框架
注册的包会拒绝该参数，导致卸载器在实际删除前失败。

- 卸载器仍优先按用户选择使用 `PreserveApplicationData`。
- 如果 Windows 明确报告该参数只适用于 deployment-mode 包，卸载器会移除该参数，
  对同一个当前用户包执行一次普通 `Remove-AppxPackage` 重试。
- 普通卸载成功后仍会复核当前用户的 `Get-AppxPackage -Name OpenAI.Codex` 已为空；
  不会把“命令返回但注册仍在”的状态报告为成功。
- 兼容性降级会在结果和日志中明确提示：该路径不能保证保留包内数据；用户数据清除开关
  仍按原有流程处理。
- 其他权限、策略、身份或锁定错误不会进入该降级路径，仍会保留原始错误并要求重试。

## 验证边界

已补充 Windows PowerShell 兼容性分类回归，并重新执行 Rust、前端、Windows 目标编译和
USB 发布目录校验。真实 AppX 注册/卸载仍需在目标 Windows 10/11 机器上验证；企业策略、
其他用户或 provisioned 包不属于当前用户卸载范围。
