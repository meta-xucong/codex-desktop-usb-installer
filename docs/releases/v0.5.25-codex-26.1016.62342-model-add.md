# v0.5.25 — Codex 26.1016.62342 and model-add flow

## Scope

- Package the current USB manager source, including the 2026-10-23 model-add flow simplification, as release `0.5.25`.
- Replace the USB bundle's Codex `26.1002.52244` / MSIX `26.1002.7124.0` payload with the newer Windows x64 Codex payload `26.1016.62342` / MSIX `26.1016.8622.0`.
- Preserve the existing USB signing key. Generate a release-specific `0.5.25` profile and matching signer directory.
- Keep existing releases and unrelated worktree changes intact.

- Source: [Codex App Mirror release 26.1016.62342](https://github.com/Wangnov/codex-app-mirror/releases/tag/codex-app-26.1016.62342).

- The current USB package being superseded contains Codex `26.1002.52244`, MSIX `26.1002.7124.0`, 941,254,056 bytes.
- OpenAI's model documentation says GPT-5.5 retired from Codex for ChatGPT sign-in on 2026-10-14; API-key Codex sessions are not affected. The bundle update therefore uses the newer Codex client metadata and does not remove GPT-5.5 from the API-key capability catalog.

## Signing decision

The USB manager requires a version-matched public signing profile at build time. This release uses the existing production key ID and public-key digest with a new `0.5.25` release ID. The signing GUI source and encrypted portable vault are unchanged, so the executable does not need recompilation; its release directory is repackaged with the new profile and regenerated hashes. No license is written to the static USB package.
