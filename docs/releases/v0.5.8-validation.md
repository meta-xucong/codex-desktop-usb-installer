## 真实目标机验收仍待执行

1. 完整复制新版目录到 NTFS U 盘，运行 `CodexDesktopSetup.exe`，批准标准 UAC。
2. 在卸载页保持默认选项，验证个人配置和源安装包保留，管理器退出后日志/缓存/状态/暂存清理。
3. 再次安装；关闭“保留我的数据”，确认 API Key、会话、Skills/MCP 配置及对应 AppX 数据备份的不可恢复清除范围。
4. 如需连同源安装包删除，另行勾选“同时删除当前 U 盘安装包”并二次确认；不要提前拔盘。
5. 检查用户可见的 `Codex-Uninstall-Report-<批次>.json`：`status=completed` 且 `helperFinalization=removed` 才代表所选范围完成；`failed/pending` 不能当成功。有意保留的共享/未知状态依然列明。

不会清空 Windows 事件日志、Prefetch、系统安装历史、共享 VC++/WebView2，不接管 WindowsApps ACL，不删除其他用户的应用、项目或未知副本。旧版没有所有权/原值记录的系统状态不能安全追溯强删。企业策略、文件仍被其他程序占用、坏盘、断盘、跨管理员账户安装等仍可能导致明确的部分失败。
