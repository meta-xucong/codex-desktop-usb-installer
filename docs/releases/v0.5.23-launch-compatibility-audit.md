# v0.5.23 启动兼容最终审计

完整问题证据、设计边界和实现说明见
[v0.5.22 启动兼容审计](v0.5.22-launch-compatibility-audit.md)。最终交付顺延为
v0.5.23，是因为正式包生成后又发现 CCSwitch 只验证了窗口“出现一次”，尚未验证
短时间稳定存在；发布工具又按设计禁止覆盖非空版本目录。

v0.5.23 在前述实现上增加 CCSwitch 两秒稳定性复核：如果尺寸正常的主窗口出现后又
消失，管理器会关闭精确 USB CCSwitch 程序根内的异常进程并返回失败，不会把瞬时
WebView2 窗口误报为配置器已可用。该行为与 Codex 的三秒稳定窗口后置条件一致。

本版必须从全新的 `release/usb-oneclick-v0.5.23-final` 目录交付。较早生成的
`v0.5.22-final` 候选未被覆盖，也不是验收对象。
