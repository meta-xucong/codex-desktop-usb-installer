# Codex App Manager v0.5.3

> 历史版本：v0.5.4 已修复本版在部分 Windows 上“sideload 返回成功但包实际落到 C: ”的
> 错盘后置校验、错盘清理和 PowerShell 超长命令行问题。交付请使用 v0.5.4 包。

## USB 安装权限回归修复

- USB 包内的 `CodexDesktopSetup.exe` 和 `CodexAppManager.exe` 均使用标准 Windows `requireAdministrator` 清单，避免管理员账户的 UAC 过滤令牌落入 AppX 卷注册流程。
- USB 高权限会话不再使用普通安装版的全局单实例锁，避免残留的低权限旧进程接管启动请求。
- 修复离线 MSIX 诊断中的第二条失败链：`canonicalize()` 产生的 `\\?\\C:\\...` 路径不再直接跨入 PowerShell/WinRT URI；脚本会先还原普通 Win32 路径，并用显式 `file:///` URI 调用原生回退。
- 构建阶段直接读取最终 PE 的嵌入清单，入口和管理器任一回退为 `asInvoker` 都会拒绝打包。
- 联合包验证额外锁定 `manager.role=requireAdministrator`，防止二进制已更新而 `usb-manifest.json` 仍残留旧版 `asInvoker` 元数据。
- 版本号提升到 `0.5.3`，避免用户误把旧的 `0.5.2` 二进制继续复制到 U 盘。

普通安装版仍保持原有 asInvoker 构建；UAC 取消、无管理员凭据、企业策略或不受支持的 AppX 卷仍由 Windows 正常拒绝。
