# v0.5.24 G39.3：404TOKEN 统一分组 API

发布日期：2026-09-20

## 变更

- 404TOKEN 新建用户固定授权到活动分组 `unified-api-internal`。
- 分组 ID 通过管理 API 按名称动态解析；同一个 ID 用于用户 `allowed_groups`、API Key `group_id` 和本地账户绑定。
- 每个新账户只创建一个 API Key。Key 创建接口不支持模型白名单字段，因此“跑所有模型”由目标分组权限提供。
- 操作界面不再允许输入任意数字分组 ID，避免把账户发到错误分组。
- 保留 USB 设备 Key 的运行时注入；发布物不包含任何 API Key。

### G39.5/r9 发布包同步

- CCSwitch 静态 provider 名称已同步为 `404TOKEN（unified-api-internal）`。
- provider 不再携带固定模型或回退模型列表，保持单个运行时 API Key 配合 `/v1/models` 获取完整模型目录。
- 新 U 盘目录：`release/usb-oneclick-g39.5-20260922-r9-unified-api-final2/`。
