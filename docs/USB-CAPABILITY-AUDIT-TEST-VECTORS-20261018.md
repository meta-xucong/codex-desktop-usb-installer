关联：`USB-CAPABILITY-AUDIT-BLUEPRINT-20261018.md`、`USB-CAPABILITY-AUDIT-CHECKLIST-20261018.md`。本文件中的提示用于当前 Codex 会话的自然触发探针；执行者应逐字提交，记录是否自动选中源 Skill。另开会话逐字点名/附加源 `SKILL.md` 属于**显式工作流检查**，不能替代自然触发证据。负例须单独新回合提交。若会话未加载 U 盘源版本，触发项状态必须是 `INSUFFICIENT_EVIDENCE`，不可把手动照文档执行计为自动发现成功。
